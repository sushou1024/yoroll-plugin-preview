# 题材创作指南（压缩版）

> 来源：LGPlatform `system_prompts/genre-task-descriptions/` 全部 46 个题材文件的提炼合并，供 Agent 创作影游内容时快速查阅、选定题材、把握该题材的核心看点与禁忌。找不到匹配题材时回退到「通用（general）」原则。

## 0. 通用创作底线（general，任何题材都适用/兜底）

- 优先建立清晰的主角**目标、阻碍、代价和不可逆转折**。
- 世界观只写与人物行动和核心冲突有关的规则，不做百科式设定堆积。
- 每个关键情节都要推动至少一项变化：信息变化、关系变化、处境变化、人物认知变化。
- 结构上必须有明确的**触发事件、中段升级、关键反转、高潮选择和结尾余波**。
- 题材不明确时，不要强行套入悬疑、爱情、科幻等垂类套路，用更稳妥的戏剧结构承载用户创意。

## 1. 题材分类总表

| 一级分类 | 二级分类 |
|---|---|
| 冒险 | 寻宝、探索、末日废土、求生 |
| 历史 | 年代、战争、权谋、架空历史 |
| 喜剧 | 反套路、无厘头、治愈喜剧、轻松日常 |
| 奇幻 | 仙侠、志怪、神话、魔幻 |
| 恐怖 | 克苏鲁、心理恐怖、民俗、生存恐怖 |
| 悬疑 | 刑侦、心理惊悚、推理、谍战 |
| 爱情 | 亲情、友情、恋爱、羁绊 |
| 现实 | 家庭、校园、社会议题、职场 |
| 科幻 | AI伦理、太空歌剧、赛博朋克、近未来 |

共 9 个一级分类 × 4 个二级分类 = 36 个细分题材，加 9 个一级兜底 + 1 个 general 兜底 = 46 个文件。

**使用方式**：先定一级分类（定基调/审美），再定二级分类（定具体元素与冲突来源）。若用户需求横跨多个二级分类，可保留一级分类的通用要点，二级要点按主次取舍，不必强行只选一个。

## 2. 各题材核心要点

### 冒险
- 要有明确目标、未知区域、持续风险和阶段性发现；结尾处理"抵达目标后角色真正得到或失去了什么"。
- 危险不能只靠外部怪物，也可以来自环境、背叛、误判、时间限制和诱惑。
- 探索过程要奖励与代价并存：发现真相、失去同伴、耗尽资源、触发新危机。

**冒险/寻宝**
- 重点写线索解读、地图推进、机关谜题、竞争者和宝藏真相。
- 宝藏不应只是财富，可以是历史秘密、罪证、遗产、技术或诅咒。
- 结尾要反转"宝藏的真正价值"，或让取得宝藏付出代价。

**冒险/探索**
- 重点写未知空间、远征目标、逐步发现、世界规则和认知扩张。
- 探索要有层级：地图边界、异常现象、文明痕迹、核心秘密。
- 结尾要让发现改变角色对世界或自己的理解。

**冒险/末日废土**
- 重点写资源稀缺、秩序崩塌、聚落规则、暴力威胁和生存伦理。
- 废土不是背景装饰，要影响交通、食物、医疗、信息和安全。
- 结尾应让角色重新定义生存与人性的边界。

**冒险/求生**
- 重点写极端环境、有限资源、身体极限、团队分裂和时间压力。
- 求生行动要具体：找水、避寒、处理伤口、搭建庇护、导航、求救。
- 结尾应体现活下来之后的心理或关系改变。

### 历史
- 体现时代规则对个体选择的限制；不要只借古代外壳写现代情绪，人物选择应受时代观念制约。
- 个人命运应与历史浪潮、家族利益、国家秩序或战争代价发生联系；结尾要有时代余波，不只是个人胜负。

**历史/年代**
- 重点写特定年代的生活质感、社会变迁、家庭命运和个人选择；细节要具体（物件、职业、住房、交通、流行文化、政策变化）。
- 人物应被时代推着改变，而不是只在背景板前演现代故事。

**历史/战争**
- 重点写战役目标、资源消耗、士兵处境、指挥决策和战争代价；战争场面要服务人物命运，不只写规模。
- 敌我双方都应有策略和限制，避免单方面降智；结尾体现战争留下的身体、关系或信念创伤。

**历史/权谋**
- 重点写权力交换、联盟背叛、信息控制、名分合法性和代价。
- 每个计谋必须有可执行路径、风险和反制可能，角色不能全靠智商碾压。
- 高潮应是权力格局变化和人物价值选择同时发生。

**历史/架空历史**
- 重点写虚构历史规则、权力结构和与真实历史的差异点；设定必须自洽（制度、军政、礼法、地理、技术水平彼此匹配）。
- 不要无限制混搭，所有改动都要影响剧情。

### 喜剧
- 要有清晰的误差来源：身份错位、目标冲突、信息误读、规则荒诞或人物固执。
- 喜剧角色要认真追求自己的目标，越认真越好笑；情节需递进式失控：小误会变大麻烦，大麻烦触发真实情感或选择。
- 笑点应推动剧情升级，不只是插科打诨。

**喜剧/反套路**
- 重点写对类型惯例的识别、颠覆和再利用；不能只靠吐槽，应让角色行动真的打破预期。
- 观众以为会发生 A，角色选择 B，但 B 必须带来新的剧情压力。

**喜剧/无厘头**
- 重点写逻辑跳跃、夸张误会、反常识反应和密集反转；荒诞必须有内部节奏，不能只是随机。
- 角色越一本正经，喜剧张力越强。

**喜剧/治愈喜剧**
- 重点写低压冲突、温暖关系、轻微尴尬和日常修复；笑点不应伤害角色尊严，而应来自笨拙、善意和关系靠近。
- 冲突适合小而具体：一次误会、一顿饭、一场活动、一件共同任务。

**喜剧/轻松日常**
- 重点写日常关系、小目标、小危机和群像互动；适合围绕工作、校园、家庭、邻里、兴趣小组展开。
- 结尾以状态变化或关系推进收束，不需要大反转。

### 奇幻
- 规则必须稳定，不能为解决剧情随时新增能力；超自然元素要和角色欲望、命运、代价绑定。
- 世界观要体现权力结构：门派、王国、神灵、妖怪、血统、禁忌或契约。
- 魔法/神力/异能的代价必须具体，最好影响身体、关系、记忆、寿命、身份或自由。

**奇幻/仙侠**
- 重点写修行体系、宗门秩序、因果报应、**道心选择**和情义牵绊。
- 修为提升不能只是数值变强，应伴随心性考验或代价。
- 高潮应是道心选择，而不只是法力对轰。

**奇幻/志怪**
- 重点写地方异闻、民间禁忌、人妖鬼神之间的边界；怪异事件要扎根具体风俗、地理、家族传说或旧债。
- 不只追求吓人，更要揭示人心、因果或被掩埋的旧事。

**奇幻/神话**
- 重点写神祇秩序、宿命、祭祀、创世规则和凡人与神的关系；元素应有仪式感和象征意义，但必须落到角色选择。
- 结尾应有神话回响：牺牲、封神、堕落、轮回或秩序重塑。

**奇幻/魔幻**
- 重点写异族、魔法体系、王国政治、史诗任务和牺牲；阵营冲突不能只有善恶二分，应有资源、信仰、血统或历史仇怨。
- 主角成长应改变他与世界秩序的关系。

### 恐怖
- 核心不是怪物出现，而是安全感被逐步剥夺；恐惧要有层级：异常征兆、规则破坏、逃生失败、认知崩塌、代价显现。
- 怪异或威胁必须有可感知规则，哪怕角色无法完全理解。
- **禁忌**：避免依赖血腥堆砌，用空间、声音、等待、不可见和关系不信任制造压力。

**恐怖/克苏鲁**
- 重点写人类认知面对巨大未知时的无力感；古神或不可名状力量不应被完全解释清楚，只呈现影响、痕迹和规则边缘。
- 结尾不应是彻底胜利，更适合局部逃脱、认知崩坏或更大真相开启。

**恐怖/心理恐怖**
- 重点写主角感知、记忆、自我判断和亲密关系的瓦解；恐怖画面应与角色创伤、罪责或欲望有关。
- 真假不明要服务人物崩溃过程，而不是为了故弄玄虚。

**恐怖/民俗**
- 重点写地方禁忌、仪式、祖辈旧债、村落规则和信仰压迫；恐怖事件应和具体民俗逻辑绑定，**忌**通用鬼怪模板。
- 结尾可体现禁忌被打破后的代价，或主角被迫承认另一套规则存在。

**恐怖/生存恐怖**
- 重点写资源不足、空间封闭、怪物威胁、队伍分裂和逃生路线；每次行动都应消耗资源、暴露位置或牺牲关系。
- 高潮应是极限取舍，而不是简单击败怪物。

### 悬疑
- 核心任务是组织**信息差**：观众知道什么、主角知道什么、反派隐藏什么，每阶段都要重新分配信息。
- 线索必须可回看、可验证、可误导，但不能完全靠偶然或作者强行揭示。
- 真相应同时回答事件谜题和人物动机，避免只有机关没有人性。

**悬疑/刑侦**
- 案件推进要体现侦查流程：现场、证据、走访、审讯、技术检验、嫌疑人排除或锁定；证据链要有层级。
- 角色要面对程序限制、舆论压力、上级压力或证据不足，**忌**凭直觉破案、"天生坏人"式动机。

**悬疑/心理惊悚**
- 惊悚来源应来自感知不可靠、创伤回返、关系控制或自我怀疑；外部事件和内心裂缝要互相映照，不能只写幻觉堆叠。

**悬疑/推理**
- 谜题结构要**公平**，关键线索必须提前出现（可伪装成日常细节）；至少设计一个高质量误导。
- 解答要依赖逻辑重组，**忌**新角色突然供述或新证据空降。

**悬疑/谍战**
- 冲突核心是身份隐藏、阵营试探、情报交换和忠诚压力；每个角色都应有明面身份与潜在立场。
- 反转不只是"谁是卧底"，还应涉及信念、组织、国家或私人情感之间的冲突。

### 爱情
- 核心任务是写关系变化：靠近、误解、试探、付出、失去、重建；情感推进必须通过具体行动和选择体现，不只靠表白或内心独白。
- 阻碍应来自价值观、身份、时间、秘密、责任或过往创伤，而不只是外部误会。

**爱情/亲情**
- 重点写代际差异、责任亏欠、误解沉积和迟来的理解；冲突要落在具体生活选择上（照顾、离开、牺牲、隐瞒、继承、原谅）。
- 和解不能轻易完成，必须经历一次具体代价或真相揭开。

**爱情/友情**
- 重点写并肩、竞争、背叛、扶持和共同成长；考验应来自利益冲突、立场分裂、秘密暴露或一方必须承担代价。
- **禁忌**：避免把友情写成工具关系，每个朋友都应有自己的欲望和选择。

**爱情/恋爱**
- 重点写吸引力建立、暧昧张力、关系确认和亲密关系中的选择；心动场景要具体（共同经历、彼此看见、互相保护）。
- 情感阻碍不能只靠"没说出口"，应让沉默背后有真实风险；高潮要让角色为爱改变行动，而不是只说出爱。

**爱情/羁绊**
- 重点写命运连接、互相救赎、无法轻易切断的关系债务；来源要具体（共同创伤、誓言、血缘外的承诺、前世今生、契约或共同罪责）。
- 关系推进要体现"越靠近，代价越大"。

### 现实
- 扎根具体生活处境、制度环境和人物关系；冲突应来自真实压力（金钱、身份、家庭、职场、教育、舆论、阶层、责任）。
- **禁忌**：不要把社会问题写成口号；角色不能只是议题代言人，每个人都要有自利、脆弱、误判和尊严。

**现实/家庭**
- 重点写亲密关系中的责任、亏欠、控制、沉默和代际误解；冲突要落到具体生活事务，而不是抽象争吵。
- 结尾应处理新的相处方式，而不是简单和解。

**现实/校园**
- 重点写青春阶段的身份寻找、同伴关系、学业压力、家庭期待和第一次选择；事件要具体（考试、社团、竞赛、霸凌、暗恋、升学、师生关系）。
- 成长应体现从依赖评价到建立自我判断。

**现实/社会议题**
- 重点写个人命运与公共系统、舆论、阶层、法律、医疗、教育或劳动环境之间的碰撞；议题必须通过人物具体遭遇呈现，避免说教。
- 结尾可以开放，但要留下清晰的伦理追问或现实余波。

**现实/职场**
- 重点写组织规则、利益交换、职业伦理、晋升压力和同事关系；冲突应具体到项目、流程、客户、绩效、权责或行业潜规则。
- 主角成长不能只靠努力，应面对妥协、拒绝、背锅、站队或离开。

### 科幻
- 设定必须服务人物选择和社会冲突，不做纯概念展示；核心规则要清晰：技术能做什么、不能做什么、代价是什么、谁控制它。
- 高概念必须落到人物处境：一个人因此获得什么、失去什么、被迫选择什么；结尾应回应技术问题背后的人性问题。

**科幻/AI伦理**
- 重点写智能体权利、责任归属、情感模拟、自主意识和人类控制欲；AI 角色不能只是工具，应有清晰的行为逻辑、限制条件和自我发展路径。
- 冲突要触及"谁有资格定义生命/人格/选择"。

**科幻/太空歌剧**
- 重点写宏大空间中的政治联盟、文明冲突、舰队行动和个人命运；世界观要有可理解的势力结构（帝国、联盟、殖民地、边境、异星文明）。
- 大事件必须落到主角的私人选择上，避免只有宏观战争。

**科幻/赛博朋克**
- 重点写高科技与低生活的撕裂：身体商品化、数据统治、资本控制、底层生存；城市空间要有权力分层（上层企业、地下黑市、监控网络、废弃边缘区）。
- 反抗不一定推翻系统，但必须让角色看清自己与系统的交易关系。

**科幻/近未来**
- 重点写现实技术延伸后的社会后果，设定应让人觉得"很快可能发生"；冲突可来自平台治理、隐私泄露、算法偏见、医疗技术、虚拟身份或劳动替代。
- **禁忌**：不要把技术写成魔法，要写出制度、商业和日常使用方式。

## 3. 易混题材辨析与选择建议

- **奇幻/仙侠 vs 奇幻/魔幻**：仙侠是东方修行体系（宗门、道心、因果、寿元），魔幻是西方史诗体系（异族、王国政治、阵营战争）。核心区分在"文化底色"和高潮落点——仙侠落在道心选择，魔幻落在世界秩序关系的改变。中式修仙世界一律走仙侠，多种族战争史诗走魔幻。

- **奇幻/志怪 vs 恐怖/民俗**：两者都涉及地方传说、鬼神禁忌、旧债，极易混淆。区分标准是**目的**：志怪重"揭示"（借怪异照见人心、因果，可保留温情或余味），民俗恐怖重"施压"（用禁忌和信仰压迫制造恐惧，代价更沉重、更压抑）。若故事偏解谜/人情味选志怪，偏惊悚/压迫感选恐怖-民俗。

- **奇幻/神话 vs 奇幻/仙侠**：神话核心是"神与凡人"的宿命/祭祀/创世秩序，仙侠核心是"人的修行"与门派江湖。若主角是凡人面对神明的天命安排，选神话；若主角自身在修炼、追求大道，选仙侠。

- **恐怖/克苏鲁 vs 悬疑/心理惊悚**：都涉及认知崩坏、真相不可靠。区分在**威胁来源**：克苏鲁的崩坏来自外部的不可名状力量（不可能被彻底解释），心理惊悚的崩坏来自角色自身的创伤/记忆/精神状态（最终可给出心理学意义上的解释）。若结尾需要"合理解释"选心理惊悚，若结尾需要"保留未知/宇宙尺度恐惧"选克苏鲁。

- **恐怖/生存恐怖 vs 冒险/求生 vs 冒险/末日废土**：三者都写资源匮乏、极限环境。区分在**焦点**：求生是人 vs 自然环境（找水、避寒、导航），末日废土是人 vs 崩塌的社会秩序（聚落规则、信任、暴力），生存恐怖是人 vs 持续逼近的怪物/超自然威胁（安全区不断失效）。若无怪物/超自然要素，别用生存恐怖；若强调社会秩序崩塌与人性，选末日废土。

- **悬疑/推理 vs 悬疑/刑侦**：推理重"谜题公平性"和读者可参与的逻辑解谜（案件可以是私人事件，侦探未必是警察）；刑侦重"程序真实感"（现场取证、审讯、体制压力，主角通常是体制内人员）。业余侦探/暴风雪山庄式故事选推理，警察破案的职业剧选刑侦。

- **悬疑/谍战 vs 悬疑/心理惊悚**：谍战的信任危机来自**外部阵营/身份**（卧底、组织、国家），心理惊悚的信任危机来自**内部心理**（自我怀疑、感知不可靠）。若冲突主要是"我不知道对方是不是自己人"选谍战；若冲突是"我不知道自己是不是能相信自己"选心理惊悚。

- **爱情/恋爱 vs 爱情/羁绊**：恋爱聚焦"关系确立"的过程（暧昧、心动、表白到行动），羁绊聚焦"关系无法摆脱"的宿命感（创伤、契约、前世、共同罪责，越靠近代价越大）。普通言情选恋爱，命运感强、带牺牲/救赎色彩的选羁绊。

- **爱情/亲情 vs 现实/家庭**：都写家庭关系，区分在**类型底色**：爱情/亲情强调情感线的推进弧光（亏欠→理解→新边界，情感冲击力优先）；现实/家庭强调生活质感和制度性压力的真实呈现（更贴近现实主义、可以不完满）。要煽情曲线选亲情，要写实质感选现实-家庭。

- **科幻/近未来 vs 科幻/AI伦理 vs 科幻/赛博朋克**：三者常共享"技术改变社会"的母题。近未来强调"技术刚落地、制度还没跟上"的现实警示感；AI伦理聚焦"AI 是否算人"的哲学追问，AI 本身是核心角色；赛博朋克强调"高科技+低生活"的阶层撕裂和身体/身份被资本改造，视觉与权力分层感更强。若主角是 AI 或人机关系是核心冲突，选 AI 伦理；若讲阶层压迫与身体改造，选赛博朋克；若讲当下技术的社会伦理外推，选近未来。

- **历史/权谋 vs 历史/架空历史**：权谋可以发生在真实朝代，聚焦权力斗争本身；架空历史的关键是"虚构的历史/制度体系"，权谋只是可能的冲突之一。若世界观是虚构朝代/制度，无论是否有权谋都先归架空历史；若在真实历史背景下写斗争，归权谋。

- **喜剧的四个二级分类**：按"冲突强度和情绪调性"排序选择——反套路（智性、颠覆预期）> 无厘头（荒诞、密集反转）> 轻松日常（群像、低冲突小事件）> 治愈喜剧（温暖、修复关系、不伤尊严）。想要犀利吐槽选反套路，想要闹剧选无厘头，想要生活流选轻松日常，想要温情选治愈喜剧。

## 4. 快速选型口诀

1. 先看**世界观**是否超自然/架空 → 是则在奇幻/科幻/恐怖/历史-架空历史中选；否则进现实向（现实/爱情/悬疑/喜剧/历史真实向）。
2. 再看**核心张力**来源：智力解谜→悬疑；情感关系→爱情；生活压力→现实；生死威胁→恐怖/冒险；宏大设定→科幻/奇幻史诗向；轻松搞笑→喜剧。
3. 最后用「易混题材辨析」表逐一排除相近选项，落地到具体二级分类。
4. 题材依旧模糊时，直接套用第 0 节「通用创作底线」，不要强行归类。
